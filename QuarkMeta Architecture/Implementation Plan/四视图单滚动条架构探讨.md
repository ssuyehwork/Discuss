## 关键发现：现有代码已完成 80% 的基础工作

### 发现一：lessThan() 类型墙已存在
[`FilterProxyModel::lessThan()`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/models/FilterProxyModel.cpp#L220-L289) 中已有明确注释：

```
绝对权重 1：文件夹永远在最上方（无视升序降序）
绝对权重 2：置顶/加密优先（无视升序降序）
第3关：用户排序字段
```

**结论**：三级比较器已完整存在，类型墙已锁死。改版后无需修改 `lessThan()`，置顶与排序逻辑天然不受影响。

### 发现二：瀑布流视图已预留分组字段
[`JustifiedView`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/JustifiedView.h) 的 `ItemGeometry` 已有：
```cpp
bool isHeader = false;
QString headerText;
bool isCollapsed = false;
```
分组标头的几何占位结构已经打好，无需从零设计。

### 发现三：filterAcceptsRow() 有一个关键逻辑需要调整
当前 [`FilterProxyModel::filterAcceptsRow()`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/models/FilterProxyModel.cpp#L22-L218) 的第1条规则：

```cpp
// 文件夹与文件显隐控制
if (record.isDir) {
    if (!currentFilter.showFolders) return false;
} else {
    if (!currentFilter.showFiles) return false;
}
```

当前双视图下，folderProxy 设置 `showFolders=true, showFiles=false`，fileProxy 设置反之，用"两个过滤器"实现文件夹/文件分离。

单视图后，只剩**一个 FilterProxyModel**，需同时通过 `showFolders` 和 `showFiles` 两个开关。这个逻辑**本身不需要改动**，只需把两个 ProxyModel 合并为一个即可。

## 四种视图的改动细节

### 视图一 & 二：列表视图 / 网格视图
**现状**：[`SectionedScrollCanvas`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/SectionedScrollCanvas.h) → [`DualSectionPanel`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/DualSectionPanel.h) → folderView + fileView

```
SectionedScrollCanvas (QScrollArea)         ← 外层已单滚动条
    └── DualSectionPanel
            ├── FolderSectionHeaderBar      ← 已有，保留
            ├── folderView (QListView / JustifiedView)
            ├── FileSectionHeaderBar        ← 已有，保留
            └── fileView  (QListView / JustifiedView)
```

**改后结构**：

```
SectionedScrollCanvas (QScrollArea)         ← 保留，简化参数
    ├── FolderSectionHeaderBar              ← 直接挂载，不再经由 DualSectionPanel
    ├── unifiedView (QListView / JustifiedView)   ← 单视图，承载全部数据
    └── FileSectionHeaderBar
```

**关键变化**：
- 双 ProxyModel → 单 ProxyModel（文件夹+文件共用）
- 双 SelectionModel → 单 SelectionModel（选区管理大幅简化）
- `DualSectionPanel` 彻底删除，两个标头控件直接由 `SectionedScrollCanvas` 管理
- 分组标头的显隐（何时出现文件区标头：有文件夹且有文件时）改由 `SectionedScrollCanvas` 控制

---

### 视图三：瀑布流视图（JustifiedView）
**现状**：与列表/网格视图共用 `SectionedScrollCanvas`，内部 `DualSectionPanel` 中 folderView 和 fileView 都是 `JustifiedView` 实例

**改后结构**：同列表/网格视图，单 `JustifiedView` + 单 ProxyModel

**额外工作**：激活 `JustifiedView` 内已有的 `isHeader` 机制，在布局引擎 `doLayout()` 中：
- 在文件夹数据行之前插入"文件夹 (N)"标头行
- 在文件数据行之前插入"文件 (M)"标头行
- 标头行响应折叠信号时，切换 `isCollapsed`，重新触发 `doLayout()` 隐藏对应区的项目

---

### 视图四：分栏视图（ColumnView）
**现状**：每个 [`ColumnViewPane`](file:///g:/C++/QuarkMeta/QuarkMeta/src/ui/ColumnViewPane.h) 内部：

```
ColumnViewPane
    ├── m_paneScrollArea (QScrollArea)   ← 已是单滚动条
    └── DualSectionPanel* m_panel
            ├── FolderSectionHeaderBar
            ├── m_folderListView (DropListView)
            ├── FileSectionHeaderBar
            └── m_listView (DropListView)
```

**改后结构**：

```
ColumnViewPane
    ├── m_paneScrollArea (QScrollArea)   ← 保留
    ├── FolderSectionHeaderBar           ← 直接持有
    ├── m_unifiedListView (DropListView) ← 单视图
    └── FileSectionHeaderBar
```

**关键变化**：
- `m_folderProxyModel` + `m_fileProxyModel` → 单 `m_proxyModel`
- `folderListView()` 接口：因 `ColumnViewPane.h` 中此方法为对外公开接口，**需评估外部调用方**后决定保留为兼容别名还是同步修改调用方
- `m_panel` 指针删除，折叠逻辑移入 `ColumnViewPane` 自身

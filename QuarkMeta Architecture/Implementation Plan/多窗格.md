💡 核心机制与物理生命周期解析
1. 二叉层次节点树 (PaneNode) 拓扑设计
QuarkMeta 的多窗格并非简单的线性平铺，而是基于二叉层次节点树实现的无限嵌套分屏：

struct PaneNode {
    bool isSplitter = false;             // 是否为 QSplitter 容器节点
    Qt::Orientation orientation = ...;  // 拆分方向 (Horizontal / Vertical)
    QPointer<QSplitter> splitter;        // 布局拆分器指针
    QPointer<QWidget> container;         // 窗格 Widget 容器
    ContentPanel* panel = nullptr;       // 绑定的视图工作台实例
    bool isPrimary = false;              // 是否为主窗格（Root ContentPanel）
    QList<PaneNode*> children;          // 子节点列表
    PaneNode* parent = nullptr;          // 父节点指针
};
2. 代理管理者 SSOT 架构 (Root Manager Proxy)
在由 1 个主窗格 + 最多 3 个副窗格（全软件上限 kMaxPanes = 4）组成的多窗格组中，主窗格 (m_panel) 的 ContentPaneSplitManager 担当全组的唯一真理源管理者。
任何副窗格（m_isSecondaryPane = true）被触发拆分、关闭或状态查询时，都会全量重定向转发至 rootPane()->m_splitManager 进行统一计算和树形重组，杜绝了多窗格状态混乱与循环递归。
3. 拆分创建的物理 7 步生命周期 (splitPane)
上限检查：校验 paneCount() >= 4，超限则拒绝新建，降级为在当前活跃窗格加载目标路径。
主容器升级 (m_primaryPaneContainer)：首次拆分时，主窗格将自身的标题栏 (m_headerWidget) 与视图栈 (m_viewStack) 封装装入 m_primaryPaneContainer (QFrame) 中，升级为二叉树的 Primary Leaf 节点。
实例化副窗格：创建全新的 ContentPanel 实例，设为副窗格（setIsSecondaryPane(true)），绑定其 m_rootPane 指向主窗格，并继承当前视图模式。
信号编排：连接副窗格的 closePaneRequested（关闭）、directorySelected（目录选择）与激活事件。
QSplitter 拓扑融合：
同向融合：若目标 Leaf 节点的父 PaneNode 恰好是相同拆分方向的 QSplitter，直接插入其 children 列表中。
异向嵌套：若父节点是不同方向，则创建一个新的 QSplitter 替换原 Leaf 位置，并将原 Leaf 与新 Leaf 挂载到新 QSplitter 下。
树规范化 (normalizeTree)：自动合并相同方向的嵌套 Splitter，消除孤儿/单子节点容器，保持 Widget 树结构最简。
尺寸均分与激活高亮：
redistributePaneSizes()：对所有 QSplitter 重新按等比例设置尺寸 (setSizes)；
refreshActiveIndicators()：高亮当前激活窗格的标题栏与激活边框（activePane="true"）；
发射 layoutChanged 广播。
4. 序列化与多标签页还原 (exportSplitState / restoreSplitState)
当切换标签页或重启软件时，exportSplitState 深度优先遍历 PaneNode 二叉树，导出 PaneTreeNode 树形序列化结构，记录路径、拆分方向与激活索引。切换回该标签页时，restoreSplitState 递归反序列化恢复 100% 完全相同的嵌套分屏状态。
5. 窗格关闭与优雅退场 (closePane)
副窗格关闭：从二叉树中摘除节点，销毁 Widget 容器，触发 normalizeTree 自动收缩合并剩余 QSplitter。
主窗格“接管”机制：如果用户尝试关闭主窗格（m_panel），系统绝不销毁主窗格！而是由首个副窗格将自身路径与视图模式“转移接管”给主窗格，随后关闭该副窗格，确保主工作台物理生命周期绝对安全稳定。
单窗格降级：当只剩 1 个窗格时，拆除容器包装，将标题栏与视图栈归还给 m_panel->m_mainLayout，平滑无缝恢复为单窗格视图。

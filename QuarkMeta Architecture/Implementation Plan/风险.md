# 风险记录
外部文件系统变更感知延迟： 若用户在应用外部（如 Windows 资源管理器或 CMD）直接删除或移动了正在 QuarkMeta 中显示的文件夹，内部 UndoManager 中的撤销栈如果仍保留该路径快照，执行 Undo 时可能会因为原路径不存在或被占用而报错。
网络邻居/USB 盘拔出异常： 虽有 DeviceWatcher 监听 driveUnmounted 信号并自动切回 computer://，但在网络共享路径（UNC 路径如 \\server\share）断开时，阻塞式 Windows 盘符 API 可能会导致 UI 线程短时间无响应（Network Timeout）。

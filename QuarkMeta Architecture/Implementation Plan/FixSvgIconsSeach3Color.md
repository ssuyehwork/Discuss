# Implementation Plan - Fix SvgIcons.h seach-3 Color Replacement

## Overview
This plan fixes the SVG string for `seach-3` inside `src/ui/SvgIcons.h`.
Currently, the stored SVG string contains `<style>.cls-1{fill:#231815;}</style>`, which hardcodes a dark black fill color `#231815` instead of `currentColor`. As a result, `SvgIconRenderer`'s `replace("currentColor", color.name())` failed to replace the color with pure white `#FFFFFF`.
Updating the SVG raw string in `src/ui/SvgIcons.h` to use `fill="currentColor"` allows `SvgIconRenderer::renderIcon` to render the icon in crisp white `#FFFFFF`.

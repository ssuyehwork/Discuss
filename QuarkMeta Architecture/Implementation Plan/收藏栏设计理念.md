您好！为您高度浓缩梳理，关于**收藏栏（FavoritePanel）**的核心功能共包含以下 4 大核心功能：

收藏栏 4 大核心功能浓缩概括
global.db 数据库持久化与路径唯一性 Guard：

数据完全收拢持久化于 SQLite global.db 数据库（favorites 表），$O(1)$ 极速读写。
路径强制 cleanPath 归一化，依托 SQL UNIQUE 约束彻底防重，保证物理路径绝对唯一。
文件夹 / 文件“双轨渲染”与真实缩略图管线分流：

文件夹项 (isDir == true)：使用矢量 SVG 图标（默认实心金色 folder_filled），右键独占 50 维 SVG 图标网格与 9 色 ColorStripPicker 调色板自定义。
非图形文件项 (!isDir && !isGraphicsFile)：渲染 Windows 系统原生程序关联图标（如 C++ 源码图标）。
图形/图片文件项 (!isDir && isGraphicsFile)：接入 ThumbnailPipelineService 三级缩略图流水线，优先直取 64px 内存微型缩略图，异步解码完成后自动刷新替换，直观呈现图片真实内容。
拖拽重排序与拖入快捷收藏：

支持侧边栏内部条目上下无缝拖拽重新排序，并通过 saveFavorites 防抖刷盘实时更新数据库 sort_order。
支持将外部文件或中间内容面板的项目直接拖入释放，快捷添加至收藏夹。
快捷导航联动与异步提图重绘：

点击文件夹实时广播目录切换；点击文件触发内容区自动高亮定位。
订阅全局 IconLoadNotifier::iconLoaded 异步提图通知，后台解算完成后自动刷新 QStandardItem 图标与视图，彻底抹平白纸/空白占位符痛点。
